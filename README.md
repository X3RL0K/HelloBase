# Hello World on Base

A simple "Hello World" smart contract deployed on the [Base](https://base.org) blockchain.

## What it does

Deploys a contract that stores the message:  
`"Hello World on Base"`

Built with Solidity and Hardhat.

## Setup

1. Clone this repo
2. Run `npm install`
3. Create a `.env` file with your `PRIVATE_KEY` and `BASESCAN_API_KEY`
4. Deploy with: `npm run deploy`

> 🌐 Use Base Mainnet or Sepolia testnet.
